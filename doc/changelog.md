# Qunix Changelog

All notable changes to Qunix are now organized by minor release under `./doc/changelog/0.*.x/`.
Each version directory contains the mandatory files: `changes.md`, `patches.md`, and `overview.md`.

The format remains based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
